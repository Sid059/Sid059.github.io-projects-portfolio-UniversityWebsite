# 🎓 University Website

A responsive university website built with HTML, CSS, and JavaScript featuring academic programs, campus life, and contact information.

## 🚀 Features
- **Responsive Design** - Works on desktop and mobile
- **Interactive Navigation** - JavaScript menus and transitions
- **Course Catalog** - Academic programs and information
- **Campus Life** - Facilities and student activities
- **Contact System** - Easy inquiry forms
